# AkTIVE Landing Page

A responsive React + Vite landing page for THE AkTIVE TRIBE.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Static community landing page. No authentication, dashboard, or backend.
- Replace provisional copy and contact details only after the organisation confirms them.
- The current hero illustration is CSS-built artwork; replace it with approved community photography when available.
- The opening wordmark animation respects reduced-motion preferences.
- Fonts currently use Fredoka for display and DM Sans for body text.
